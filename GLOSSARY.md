# Lumo Hub — ядро знаний (RAG)

Lumo Hub — ассистент по технической документации инженера слаботочных систем
(СКС, АПС/СПС, СКУД, ИТСО, ГОСТ/СП). Глоссарий фиксирует язык RAG-слоя:
импорт документов, поиск и выдачу фрагментов в чат.

## Language

**Корпус**:
Совокупность импортированных документов с текстовым слоем, доступных для поиска.
_Avoid_: база знаний, коллекция, архив

**Документ**:
Импортированный файл (PDF, TXT, MD) с извлекаемым текстом; единица хранения и
цитирования.
_Avoid_: файл, книга

**Чанк**:
Фрагмент документа, нарезанный по абзацам; единица индексации и поисковой
выдачи.
_Avoid_: отрывок, кусок, сегмент

**Цитата**:
Ссылка на источник фрагмента в формате [документ, стр. N], обязательная для
ответов по корпусу.
_Avoid_: сноска, reference

**Чувствительный документ**:
Документ, исключённый из AI-контекста: его фрагменты не попадают в модель ни
при каком поиске. В приложении пользователь видит и ищет по нему без
ограничений.
_Avoid_: секретный, закрытый

**Режим поиска**:
Состояние чата, при котором ответ на вопрос готовится через поиск по корпусу
(«сначала поиск»). Выключенный режим — свободный диалог с моделью без доступа
к корпусу.
_Avoid_: search-first, предпоиск

**Поисковый цикл**:
Прохождение одного вопроса пользователя через серию поисковых запросов модели
до удовлетворительного ответа; после ответа цикл начинается заново с нового
вопроса.
_Avoid_: сессия, задача

**Итерация поиска**:
Один запрос модели к поиску по корпусу в рамках поискового цикла.
_Avoid_: шаг, вызов

**Локальный** (о RAG):
Хранение корпуса и поискового индекса на устройстве; вывод выполняется
удалённо выбранным пользователем провайдером. Не означает офлайн-вывод.
_Avoid_: офлайн, приватный, on-device

**Свой провайдер**:
OpenAI-совместимый API, предоставленный пользователем (endpoint + ключ в
Android Keystore).
_Avoid_: BYO-ключ, внешний сервис

**Системная инструкция**:
Базовый текст system-промпта приложения: хранится в файле SYSTEM.md,
отображается и редактируется пользователем в настройках. Поисковый протокол в
него не входит — добавляется отдельным фиксированным блоком (в режиме поиска).
_Avoid_: system prompt, промпт

**Дополнительный документ**:
Документ, сохранённый рядом с одноимённым существующим после выбора «оставить
оба» в диалоге переимпорта; помечен бейджем «(Additional)» и участвует в поиске
наравне с остальными.
_Avoid_: дубликат, копия
